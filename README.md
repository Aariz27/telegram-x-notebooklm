# 🤖 Telegram x NotebookLM

Send a voice note or message to your Telegram bot → get back podcasts, slide decks, reports, quizzes, and more — automatically generated by NotebookLM.

## How It Works

1. You send a voice note or text to Telegram describing what you want
2. n8n transcribes it, classifies the intent, and dispatches this GitHub Action
3. GitHub Action: researches sources → generates the artifact → sends the file back to your Telegram

## Required GitHub Secrets

Go to Settings → Secrets and variables → Actions and add:

| Secret | Description |
|--------|-------------|
| `NOTEBOOKLM_AUTH_JSON` | Contents of `~/.notebooklm/storage_state.json` (run `notebooklm login` locally first) |
| `TELEGRAM_BOT_TOKEN` | Your Telegram bot token from @BotFather |
| `TELEGRAM_CHAT_ID` | Your chat ID from @userinfobot |

## Workflow Inputs (sent by n8n)

| Input | Required | Description |
|-------|----------|-------------|
| `notebook_title` | ✅ | Title for the notebook |
| `artifact_type` | ✅ | `audio`, `slide-deck`, `report`, `quiz`, `flashcards`, `mind-map`, `infographic`, `video` |
| `artifact_length` | ❌ | `short`, `default`, `long` (default: `short`) |
| `research_query` | ❌ | Search query for deep web research |
| `source_urls` | ❌ | Comma-separated URLs to add as sources |
| `briefing_text` | ❌ | Plain text to add as a source |

## n8n Setup

1. Import the Telegram classifier workflow
2. Add n8n Variable: `GITHUB_TOKEN` (fine-grained PAT with Actions: write permission)
3. In the GitHub dispatch HTTP Request node, set URL to:
   `https://api.github.com/repos/Aariz27/telegram-x-notebooklm/actions/workflows/generate.yml/dispatches`

## Getting Your NotebookLM Auth

```bash
pip install notebooklm-py
notebooklm login
cat ~/.notebooklm/storage_state.json  # paste this into the NOTEBOOKLM_AUTH_JSON secret
```
